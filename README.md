# ihva-pdf
Клиентский генератор PDF заказа (pdfmake, всё в браузере). Вставьте JSON заказа, выберите «Всё / Только Givaudan / Всё кроме Givaudan», нажмите «Сформировать».

Классификация позиций (по порядку проверки): вода (vendor/название «Парфюмерная вода») → флаконы (название содержит «флакон» или папка 387410909) → аксессуары (название «картридж» или папка 387410709) → по params «Завод»: Givaudan, Luzi, прочие заводы (Seluz и т.д., после Luzi). Сортировка внутри группы: бренд (vendor), затем название. Итог на наклейке = сумма price_discount × amount только по включённым позициям.
