# ihva-pdf
Генератор термоэтикеток 58×40 мм (pdfmake, всё в браузере). Одна позиция = одна этикетка, затем этикетка заказа (адрес/доставка/сумма) и этикетка «Комментарий» (если он есть).

Группы: вода → флаконы (в названии «флакон» / папка 387410909) → аксессуары («картридж» / папка 387410709) → по params «Завод»: Givaudan, Luzi, прочие заводы. Порядок вывода: Givaudan, Luzi, прочие заводы, флаконы, аксессуары, парфюмерная вода; внутри группы по названию. Сумма на этикетке заказа = Σ price_discount × amount только по включённым позициям.
